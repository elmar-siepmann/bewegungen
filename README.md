# Bewegungen mit Folgen und Python

Notebooks und Arbeitsblätter für einen Kurs, in dem Bewegungen mit Folgen analysiert und simuliert werden. Die Notebooks laufen direkt im Browser:

➡️ **https://elmar-siepmann.github.io/bewegungen/lab/index.html**

- `content/` enthält die Notebooks und die Messdaten (`content/data/`).
- `content/arbeitsblaetter/` enthält die Arbeitsblätter zu den Notebooks als PDF.
